# EduTrack

EduTrack is a full-stack web application developed as a **college group project**. The project was created to simplify educational management by providing an interactive and user-friendly interface for students and faculty.

## 📌 My Contribution

I contributed to the **frontend development** of the project.

My responsibilities included:
- Developing responsive user interfaces using HTML, CSS, and JavaScript.
- Designing and implementing application pages.
- Connecting frontend components with backend APIs.
- Improving the overall user experience.
- Testing and fixing UI-related issues.

> **Note:** The backend of this project was developed by other team members using Node.js, Express.js, and MongoDB.

---

## 🚀 Features

- Responsive User Interface
- Student Dashboard
- Course Management
- Attendance Tracking
- Assignment Management
- API Integration
- Interactive Forms
